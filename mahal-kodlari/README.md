# Mahal kodları (EK-3)

Yönetmeliğin EK-3'ündeki 152 mahal (oda/hacim) adı ve üç harfli kısaltması. Mahal kodu, BIM modelinde `IfcSpace` nesnelerinin adlandırılmasında kullanılır.

| Alan | Açıklama |
|---|---|
| `kod` | Üç harfli kısaltma (tekrarsız, büyük harf) |
| `ad` | Mahal adı |

Aranabilir tablo: [forumcad.com/bim/mahal/](https://forumcad.com/bim/mahal/)
